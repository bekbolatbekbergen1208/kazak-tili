The SVG library permits personal/commercial website and software use. It does
not permit redistributing an unmodified collection as one's own. This project
adds interactive learning, geographic selection, movement and progress. The
path geometry is extracted unchanged into boundaries.json and attributed in UI.
No raw map collection is distributed. Rendering changes colors and labeling.

20 features: 17 regions and 3 republican cities, including Abai, Zhetysu, Ulytau.
Display projection: Mercator. Label points are taken from source, not centroids
invented for regions. These display coordinates share the map camera. Gameplay
paths and illustrative object placement are not navigation instructions.

All TravelIcon and character SVG drawings are original project code. No remote
photos, trademarked company illustrations or third-party sounds are bundled.
Kazakh speech is shown only when a kk-language browser voice exists and the
learner enables speech. Playback requires pressing the listen button.
