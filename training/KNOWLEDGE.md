# Досжанның қазақ тілі бойынша білім базасы және оқыту деректері

Қазақ тілі материалдары анықтамалық жауапқа, AI контекстін іздеуге және оқыту экспортына ортақ. Нақты мысал тек тіркелген сұраққа сәйкес келгенде дайын жауап ретінде беріледі. Өзге еркін мәтінді талдау үшін жұмыс істейтін тіл моделі қажет.

## Материалдар

- `lib/friend/grammar*.ts`: грамматиканың 74 тақырыбы.
- `lib/dosha/kazakh-examples.ts`, `kazakh-extra-examples.ts`, `kazakh-practice-examples.ts`: барлығы 148 нақты талдау, салыстыру, емле/тыныс белгісін түзету және аударма үлгісі.
- `training/dialogue-rows.ts`, `practice-dialogues.ts`: 20 көпқадамды диалог. Нақтылау, контекстке сай түсіндіру, орысшаға ауысу, қате жауапты түзету, тапсырманың жауабын уақытынан бұрын ашпау қамтылған.
- `lib/dosha/exercises.ts`: сабақтар мен ойындардың нақты тапсырмалары, жауаптары және түсіндірмелері. Сұрақ қайталанса, сабақ нөмірі, кітап немесе өңір атауы қажет болуы мүмкін.
- `training/vocabulary-rows.ts`: сөздердің екі бағыттағы аудармалары және сөйлем мысалдары.

Жаңа 100 үлгіде сөзжасам, көптік/тәуелдік/септік айырмасы, етістіктің шақ пен жақ тұлғалары, сыпайы қатынас, сан есім, шырай, омоним, тұрақты тіркес, сөйлем мүшелері, құрмалас сөйлем, буын мен дыбыс, төл сөз, мәтіннің негізгі ойы және табиғи аударма бар. Дұрыс сөйлемді орынсыз түзетпеу және белгісіз контексті нақтылау мысалдары да енгізілген.

Күрделі тұстарды салыстырған дереккөздер мен тексеру шегі: [SOURCES.md](SOURCES.md).

## Экспорт пен тұтастық тексеруі

```sh
npm run training:dataset
python3 training/validate_data.py
python3 -m unittest discover -s training -p 'test_*.py'
npm run typecheck
npm test
```

2026-09-30 соңғы экспорт: **9514 оқыту, 380 тексеру жазбасы**. 173 дәлме-дәл қайталанған диалог алынып тасталды, 28 топ біріктірілді. Нақты сан мен тазалау нәтижесі `training/data/manifest.json` ішінде сақталады. Генерацияланған JSONL файлдары Git-ке кірмейді; бастапқы TypeScript материалдары Git арқылы таралады.

Manifest әр JSONL файлының SHA-256 мәнін де сақтайды: файлдарды басқа оқыту ортасына көшіргенде дәл сол экспорт жеткізілгенін салыстыруға болады.

`dataset-quality.ts` бірдей модель кірісіне берілген әртүрлі дұрыс жауаптарды бір train/validation тобына біріктіреді. Бұл, мысалы, teacher → мұғалім және teacher → ұстаз нұсқаларының екі бөлініске кетуін болдырмайды. Дәл қайталанған диалогтың бір данасы қалады; өзге дұрыс жауап жойылмайды. Көпқадамды диалог бастапқы мысалымен бір топта сақталады.

`validate_data.py` бос файлды, қате диалог ретін, қайталанған ID/диалогты, бөліністер арасындағы ортақ топты, бірдей диалогты немесе бірдей толық модель кірісін қабылдамайды. `train_dosha.py` осы тексеруді модельді жүктеуден бұрын орындайды.

Оқыту сәтті аяқталса, адаптер мен токенизатор сақталады, содан кейін соңғы модель тексеру жинағында бағаланады. Қысқа оқыту 100 қадамға жетпесе де, қорытынды бағалау орындалады. `train_results.json` және `eval_results.json` оқыту checkpoint қалтасына жазылады. Бұл механизм [Transformers Trainer-дің evaluate/save_metrics әдістерін](https://huggingface.co/docs/transformers/main_classes/trainer) қолданады. Скрипттің синтаксисі тексерілді; GPU ортасындағы толық орындалуы осы сессияда тексерілген жоқ.

Бұл тексерулер қазақ тіліндегі әр жауаптың ғылыми не тілдік дұрыстығына кепілдік бермейді. Жаңа материалдың адам сарапшысының толық тексеруі жүргізілген жоқ.

## Оқытуға кірмейтін бағалау

`evaluation-cases.ts` ішінде 30 бөлек сұрақ пен әр жауапты тексеруге арналған өлшемдер бар. Экспорт осы сұрақтарды және олардың диалогындағы пайдаланушы хабарламаларын оқыту жинағынан іздеп, табылса қатемен тоқтайды. Бұл — авторлық бағалау тапсырмалары; сыртқы стандартталған benchmark емес.

Анықтамалық режимді бағалау:

```sh
npm run training:evaluate -- --mode reference
```

Серверлік модельді бағалау үшін орта айнымалыларында `OLLAMA_BASE_URL` және `OLLAMA_MODEL` орнатыңыз. CLI орта айнымалыларын оқиды; `.env.local` файлын өздігінен жүктемейді.

```sh
npm run training:evaluate -- --mode model
```

`--limit 5` алғашқы бес сұрақты ғана орындайды. `--output path/to/report.json` есеп орнын анықтайды. Әдепкі есеп `training/artifacts/` ішіне жазылады; бар файлдың үстінен жазылмайды. Бұл командалар модель салмақтарын өзгертпейді.

Есеп әр сұрақты, тарихын, алынған жауапты және тексеру өлшемдерін сақтайды. `review.criteria` ішіндегі `null` мәндерін адам тексеріп, `true` немесе `false` деп толтыра алады; түсіндірме `review.notes` ішіне жазылады. `generated` — жауап алынғанының саны, дұрыстық бағасы емес. Провайдер қатесі жауап болып саналмайды және оның ішкі мәтіні есепке жазылмайды.

CLI жүйелік нұсқауларды, тапсырма тарихын және жергілікті каталогтан табылған контексті қолданады. Ол Supabase-тегі жеке жадыны, мұғалім мақұлдаған түзетулерді немесе пайдаланушының оқу профилін жүктемейді; сондықтан есепті қолданбаның толық пайдаланушы сессиясын тексеру деп қарастыруға болмайды.

Анықтамалық режимнің бастапқы есебі: 30 сұрақ өңделді, 21 сұрақта дайын жауаптың жоқтығы көрсетілді. Қалған жауаптардың арасында тек жалпы ереже не сөздік мақаласы берілген жағдайлар бар. Бұл еркін сұраққа толық жауап беру сапасының жеткіліксіздігін көрсетеді; тірі модельдің сапасы осы ортада өлшенген жоқ. Есепті жаңа модельмен қайталап, барлық жауапты өлшемдерге сай қарап шығу керек.

## Нақты модельді оқыту күйі

Модель салмақтары осы өзгерістер кезінде оқытылған жоқ. Қолданыстағы `train_dosha.py` үшін PyTorch, Unsloth және үйлесімді GPU ортасы қажет. Осы жергілікті ортада олар қолжетімсіз, Ollama серверінен де жауап алынбады. Оқыту деректерін көбейту модельді іске қосу мен салмақтарды оқытуды алмастырмайды.

Vision үшін белгіленген суреттер `training/vision-images/<word-id>/` ішінде қажет. Қазіргі Vision экспорты бос. Оның тексеруі бос жинақты қате деп көрсетеді:

```sh
python3 training/validate_data.py --vision --train training/data/dosha-vision-train.jsonl --validation training/data/dosha-vision-validation.jsonl
```

Жарияланатын нұсқа жеке көшірмеде тексерілді: production build, барлық 99 Node тесті және 9 Python тесті өтті. Жергілікті бос `202609100010_friendships_vision.sql` өзгерісі commit-ке енгізілмейді; жарияланатын нұсқада репозиторийдегі толық миграция сақталады. Бастапқы жұмыс қалтасындағы пайдаланушы өзгерісі сақталды.
