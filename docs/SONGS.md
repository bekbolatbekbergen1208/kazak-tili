# «Әнмен үйрен» — QazaqDos

Бөлім `/learn/songs` мекенжайында, әр сабақ `/learn/songs/[lessonId]` арқылы ашылады. Навигация мен оқу кабинетінде сілтемелер бар. Қолданыстағы дизайн өзгермейді: жаңа бөлім бұрынғы түстерді, батырмаларды, Досша суретін және анимация параметрін қолданады.

## Архитектура және сақтау

Next.js App Router / React / TypeScript; Supabase Auth; `LearningProvider`, `applyAction` және `/api/learning` API қолданылады. Бөлімнің JSON күйі `qd_learning_states.state.progress.songs` ішінде сақталады. Жаңа кесте немесе миграция қажет емес. Аккаунттар үшін бұрынғы learning және server-owned progress миграциялары, сервердегі Supabase кілті қажет. Демо режимі бұрынғы `qazaqdos-learning-demo-v1` браузер қоймасын қолданады, аккаунт прогресімен араласпайды.

Сақталатын дерек: бастапқы деңгей таңдауы, ең соңғы сабақ пен өзгеру уақыты, әр сабақтың кезеңі, қаралған сөздер, ойынның соңғы жауабы/дұрыстығы/әрекет саны, мәтіндік сөйлеу жаттығуы, өз сөйлемдері, қорытынды жауаптар, аяқталу уақыты, берілген XP, қате сөздердің соңғы қайталау нәтижесі/уақыты мен келесі мерзімі, жеке әнге арналған соңғы мәтіндік жоба. Дауыс файлдары бұл күйге қосылмайды. Бас бет соңғы аяқталмаған сабақтың атауы мен кезеңін көрсетеді; XP көрсеткіші сақталған марапаттан есептеледі.

`/api/learning` пайдаланушыны cookie-сессиядан анықтайды; клиенттен user_id немесе XP қабылдамайды. Сервер канондық контент арқылы жауаптарды тексеріп, кезекті кезеңге өтуге рұқсат береді. Бар сақтау revision шартымен орындалады: бір мезгілдегі екінші немесе ескірген жазу қабылданбайды. RLS басқа пайдаланушының күйін оқуға жол бермейді; authenticated/anon тікелей күй жазуға құқығы жоқ.

Бір сабаққа 20 XP бір рет: барлық мәтіндік ойын, алты кезең, сөйлеудің мәтіндік баламасы, 2–3 өз сөйлемі және екі қорытынды сұрақ керек. `song-[lessonId]` транзакциясы мен completedAt қайта марапаттаудан қорғайды. Сөз ашу/сақтау, жеке ән жасау және қайталау XP қоспайды. Өз сөйлемдері тек сөйлем саны және сабақ сөзінің қолданылуы бойынша тексеріледі: бұл толық грамматика/тіл деңгейін бағалау емес. Дауыс жазу міндетті емес және марапат шарты емес.

## Контент

Бес жаңа оқу мәтіні: «Сәлем, досым!», «Менің отбасым», «Менің күнім», «Ақтауға саяхат», «Менің арманым». Әрқайсысы 7–12 минутқа жоспарланған, 5–8 сөз, оқу мақсаты, қарапайым грамматикалық үлгі, жаңа қысқа мәтін, төрт мәтіндік ойын, болашақ тыңдалым тапсырмасы, сөйлеу жаттығуы, үш диалог сұрағы және екі қорытынды тексеруді қамтиды.

Тыңда → Түсін → Ойна → Айт → Қолдан → Қайтала — ұсынылған оқу моделі. Ғылыми дәлелденген авторлық әдістеме және ресми сертификаттау туралы мәлімдеме жоқ. Танымал әндердің мәтіні мен жазбалары көшірілген жоқ. A1/A2/B1 — оқу мазмұнының шамамен белгілері. Бар Q-Level нәтижесі болса, сол қолданылады; болмаса бастапқы деңгей таңдалады. Турист бағытына сәлемдесу, жол сұрау, көлік, кафе, қонақүй ұсынылады.

Сөзді басқанда осы сабақтағы мағынасы, негізгі тұлғасы, RU/EN аудармасы, қарапайым мысалы және мәтіндегі формалары ашылады. «Менің сөздеріме қосу» бар Literary LanguageProvider API арқылы ортақ жеке сөздікке сақтайды; сақталған сөз кейін қолданыстағы SRS жүйесінде де қайталана алады. Қате ойын сөздері бөлек ән қайталау тізіміне түседі; дұрыс жауаптан кейін 1 күн, қате жауаптан кейін 10 минут. Бұрын дұрыс қайталанған сөзге жаңа қате жіберілсе, ол қайтадан бірден қолжетімді болады. Қорытынды «тапсырмада бекіткен», «қайталау қажет» және «оқып танысқан» сөздерді нақты жауаптарға сүйеніп көрсетеді; толық меңгеру туралы кәсіби баға қоймайды. Шексіз XP жоқ.

## Аудио және микрофон

**Қазір бес сабақтың музыкалық аудиосы жоқ.** UI «Бұл сабақтың аудиосы әзірленіп жатыр» деп көрсетеді. Тыңдалым ойыны аудио қосылғанша ашылмайды; мәтіндік төрт ойынмен аяқтау мүмкін. Жаңа сессияларда төртінші мәтінді түсіну тапсырмасы бар; бұрын басталған сессияларға жаңа міндетті қақпа қосылмайды, олардың progress ID-лары сақталады. Мәтіндік айту режимі жолды қолдан белгілеуге мүмкіндік береді; уақытпен синхрондалған караоке деп көрсетілмейді.

Құқығы бар дайын аудионы `public/songs/` ішіне қосып, `lib/songs/content.ts` ішіндегі сабаққа мына деректерді енгізіңіз:

```ts
// Бұл — тек құрылым үлгісі; репозиторийде бұл файл жоқ.
audio: { src: "/songs/salem.mp3", license: "QazaqDos original recording; approved rights" },
timings: [
  { start: 0, end: 4.2 },
  // Аудиодан өлшенген нақты секундтарды қолданыңыз.
]
```

Плеер HTML audio controls арқылы ойнату/кідірту береді, қосымша қайталау және 0.75×/1×/1.25× жылдамдық бар. Уақыт белгілері бар жолды басу үзіндіні бастайды, end кезінде тоқтатады. Файл қатесі түсінікті хабарламамен өңделеді. Әр тыңдалым тапсырмасының `line` нөмірі мен дұрыс жауабын аудиомен тексеріңіз. Қазіргі деректерде аудио мен уақыт белгілері әдейі бос.

Дауыс жазу тек пайдаланушы батырманы басқанда `getUserMedia` арқылы басталады. HTTPS/localhost, браузер қолдауы және микрофон рұқсаты қажет. Жазба ең көбі 60 секунд; local Blob арқылы ойнатылады және өшіріледі; беттен шыққанда stream тоқтайды, Blob URL жойылады. Серверге жүктеу API-ы жоқ. Рұқсат берілмесе/құрылғы болмаса, мәтіндік балама бар.

Бөлек, ерікті SpeechRecognition батырмасы танылған мәтінді көрсетеді. Браузер провайдері аудионы сыртта өңдеуі мүмкін екені алдын ала жазылған. Бұл кәсіби айтылым бағасы емес; жалған пайыздар көрсетілмейді. Жеке әннің «Мәтінді дауыстап оқу» мүмкіндігі тек жүйеде kk дауысы болса жұмыс істейді; қолжетімсіздік түсіндірілген. TTS музыка жасамайды.

## Досша

Сабақ диалогы бар `/api/ai-friend` API-ына өтеді. Сервер `song.lessonId`-ді канондық сабақтан тексеріп, тек деңгей, негізгі сөздер, диалог нұсқауы және оқушының соңғы жауабын береді. Жеке чат тарихы ән диалогымен алмастырылмайды. Live режим бұрынғы Ollama/Dosha сервер баптауын, лимиттерін және тіл сапасының тексеруін қолданады. Анықтамалық режим белгілі табиғи тіркес түзетуін, бір қосымша мысал және келесі сұрақты береді; барлық грамматикалық қатені бағаламайтынын айтады. Сервис қатесі оқу мәтінін сақтауға және сабақты аяқтауға бөгет болмайды.

`/api/songs/generate` — мәтін генерациясы ғана. Тақырып және 3–4 сөйлем серверде тексеріледі. Аккаунт пен нақты модель барда ортақ `requestDossha` клиенті арқылы 4–8 жол сұратылады; жауап құрылымы/жасыңа сай болуы тексеріледі. Модель жауап бермесе, немесе демода, оқушының сөйлемдерін сақтап, екі оқу қайырмасын қосатын анықтамалық үлгі көрсетіледі. Сөздік және екі жаттығу бар. Робототехника тақырыбы үшін робот, құрастыру, бағдарлама, сенсор және қозғалыс сөздері дайындалған. AI жасаған мәтін оқушы берген ақпаратпен салыстырылуы керек. Генерация нәтижесі осы бетте, ал кіріс мәтіндік жоба прогресте сақталады.

API кілті браузерге берілмейді; жаңа музыка сервисі мен кілті қосылған жоқ.

## Тексеру

Unit тесттері бес сабақтың контентін, ойындарды, кезең шектеулерін, XP қайталанбауын, ескі күймен үйлесімділігін, қате сөздердің қайталауын және Досша/генерация шекараларын тексереді. PGlite сынағы бар кестенің жеке оқылуын, серверлік жазу құқықтарын және revision шартын тексереді. Браузер сынақтары компьютерде/телефонда толық сабақ, refresh, сөздік, қате жауап, микрофонның рұқсатсыз күйі, сервис қатесі, сүзгілер, Q-Level және мәтін генерациясын қамтиды.

Нақты музыкалық аудио, live модельдің сапасы, нақты құрылғының микрофоны және қазақша SpeechRecognition дәлдігі осы жергілікті сынақтармен расталмайды. Олар дайын аудио мен тиісті сыртқы сервис/құрылғыда жеке тексеруді күтеді.
