# Айгүл және Дәулет: тыңдалым

Оқу бөлімі: `/learn/listening`. Үш авторлық диалог, әрқайсысына төрт сұрақ. A1/A2 — мазмұнды жоспарлауға арналған болжамды белгілер; сарапшы тексеруі мен пилот қажет. Q-Level бағалауы өзгермейді.

## Azure-ді қосу

Azure Portal ішінде Speech ресурсын **Free F0** тарифімен жасау қажет. Бар ресурс болса, тарифін тексеріңіз. Жаңа ақылы ресурс автоматты жасалмайды.

`Keys and Endpoint` бөліміндегі кілт пен region-ді жергілікті `.env.local` ішіне енгізіңіз:

```
AZURE_SPEECH_KEY=...
AZURE_SPEECH_REGION=westeurope
```

Region мысал ғана: ресурстың нақты region мәнін қолданыңыз. Кілтті чатқа, Git-ке немесе NEXT_PUBLIC айнымалысына салмаңыз.

Жоспарды тексеру (API шақырмайды):

```
node --import tsx scripts/generate-listening.ts
```

Аудио жасау (Azure сұраулары, өз ресурсыңыздағы тариф/қалдық лимит қолданылады):

```
node --import tsx scripts/generate-listening.ts --generate
```

Жоспарланған топтама 3365 SSML таңбасы. Бұл Azure есепшотының қалған тегін квотасын тексеру емес. Скрипт 20000 таңбадан үлкен топтаманы тоқтатады, тарифті өзгертпейді. Кілтсіз тоқтайды; қате жауап денесін/кілтін баспайды. MP3 файлдар `public/audio/listening/` ішінде SSML хэшімен сақталады: өзгермеген файл қайта жасалмайды, бұрынғы файлдар өшірілмейді. Сайтта тек нақты бар файл ойнатылады. Аудио жоқ кезде сұрақтар бұғатталады; браузердің кездейсоқ дауысына ауыстырылмайды.

Дыбысты шығарғаннан кейін екеуінің де қазақша дыбыстарын, сандарын, кідірісін және мәтін сәйкестігін тыңдап тексеру керек. Тек содан кейін сайтқа MP3 пен код бірге енгізіледі. Оқушылар әр тыңдаған сайын Azure API шақырылмайды. Жаттығу бағасы осы бетте ғана көрсетіледі, аккаунтқа/XP-ге жазылмайды. Мәтін ашылғаны нәтижеде белгіленеді.

Ресми деректер:
- https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support
- https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech
- https://azure.microsoft.com/en-us/pricing/details/speech/

## Azure аккаунтынсыз сынақ: Edge TTS

Пайдаланушының балама құралға берген рұқсаты бойынша `edge-tts` адаптері қосылды. Бұл Azure API емес: Microsoft Edge онлайн TTS қызметіне арналған үшінші тарап клиенті. Аккаунт/API кілті талап етілмейді, қызмет қолжетімділігіне кепілдік берілмейді. Сайттағы ойнату дайын MP3 файлдардан жүреді.

```
python3 -m venv /tmp/qazaqdos-tts-env
/tmp/qazaqdos-tts-env/bin/pip install edge-tts==7.3.1 imageio-ffmpeg==0.6.0
node --import tsx scripts/listening-plan.ts > /tmp/qazaqdos-listening-plan.json
/tmp/qazaqdos-tts-env/bin/python scripts/generate-listening-edge.py /tmp/qazaqdos-listening-plan.json
```

Скрипт алдымен екі қазақша дауысты каталогтан тексереді. Әр реплика өз дауысымен жасалады, арасына 600 мс үзіліс қосылып MP3 біріктіріледі. Дайын файл толық декодтаудан өтеді. Қызмет атауы, мәтін хэші, SHA256 мен көлемі жанындағы JSON-да сақталады; UI сол деректен Microsoft Edge не Azure деп көрсетеді. Диалог мәтіндері ғана қызметке жіберіледі, оқушы деректері жіберілмейді.

Клиенттің ресми репозиторийі: https://github.com/rany2/edge-tts

## Сабақтар мен Q-Level интеграциясы

Қосымша 46 MP3: Q-Level-дің 10 сұрағы, оқу бөлімдерінің 16 тыңдау/айтылым үлгісі және 1000 каталог сабағында қайталанатын 20 сөйлем. Үш ұзақ диалогпен бірге барлығы 49 файл. Каталогтың бұрынғы төрт тапсырмасы өз ретін/ID-сін сақтайды, тыңдалым бесінші тапсырма болып қосылды. Оқу прогресі мен бұрын есептелген марапаттар өзгермейді.

Қосымша топтаманы қайта жасау (бар файлдар сақталады):

```
node --import tsx scripts/listening-phrase-plan.ts > /tmp/qazaqdos-listening-phrases.json
/tmp/qazaqdos-tts-env/bin/python scripts/generate-listening-edge.py /tmp/qazaqdos-listening-phrases.json
```

`phrase-assets.json` тек оқу фразаларын қамтиды. Тесттің `q-level-assets.json` картасы мәтін бойынша емес, сұрақ ID-сі бойынша жасалады және тек серверде қолданылады. Екі карта да кодпен және MP3 файлдарымен бірге жеткізіледі. Edge генераторының шегі: 60 жазба/15000 мәтін таңбасы, сұраулар кезекпен 3.2 секунд кідіріспен орындалады. Дайын файлдар қолданылғанда сайтқа Edge не Azure қосылымы қажет емес.

Тексеру: 160 unit тест, нақты MP3 ойнататын desktop/mobile браузер сынақтары, Q-Level quick/full өтуі, транскрипттің audio API-де жасырылуы, тыңдалым жауабының оқу прогресіне сақталуы, файлдардың SHA256 және толық декодталуы. Акустикалық және педагогикалық сапа үшін қазақ тілі маманының тыңдап сараптауы әлі қажет.
