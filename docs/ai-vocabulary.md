# Досжанның сөздік және білім қоры

`lib/translation/vocabulary.ts` сайттың оқу каталогтарынан ортақ сөздік жасайды: жалпы сөздік, өңірлер, бастапқы сөздер, суретпен үйрену, кітаптар, тарихи нысандар, сабақтар және ұлттық ойындар. Бірдей жазылған сөздер біріктіріледі; әртүрлі түсіндірмелері сақталады. Жоқ аудармалар ойдан жасалмайды. Сабақтағы сөздерге берілген сөйлем — тақырып контексті, жеке сөздің аудармасы емес.

Осы қор `/api/translate`, Досжанның контекст іздеуі және AI қосылмаған кездегі сөз түсіндіру режимінде қолданылады. Жаңа сөзді тиісті оқу каталогына қосу жеткілікті. Іздеу нақты сөзді тақырыптық материалдан жоғары қояды; жауапқа ең көбі алты дереккөз беріледі.

Білім қорына өңір карточкалары, кітап бөлімдері, тарихи нысандар, грамматика және ұлттық ойындардың түсіндірмелері де кіреді. Бұл оқу мазмұнын пайдаланады; интерфейс батырмаларын, пайдаланушы хаттарын немесе құпия баптауларды оқыту деректеріне қоспайды.

Қосымша сөздер мен авторлық сөйлемдер `lib/translation/expanded.ts` файлында сақталады. Қазіргі қорда 588 сөз бен тіркес бар; бәріне орысша және ағылшынша аударма берілген. Қосымша каталогтың 394 жазбасы жаңа сөздерді де, бұрын аудармасы болмаған сөздерді де қамтиды. Көпмағыналы сөздердің аудармалары нүктелі үтірмен бөлінеді. Іздеу орысша-ағылшынша жеке аудармаларды да таниды, ал тырнақшадағы белгісіз сөзге басқа сөздің жауабын бермейді.

`training/vocabulary-rows.ts` қазақшадан аудару, қазақшаға аудару және мысал сөйлем құрау тапсырмаларын жасайды. Бір сөздің анықтамасы, сурет сөздігі және тапсырмалары бір `group` мәнімен бөлінеді: олар оқу және тексеру жинақтарының екеуіне қатар түспейді. Бұл барлық тақырыптардың семантикалық тәуелсіздігіне кепілдік бермейді. Қазіргі мәтіндік жинақ: 4622 оқу мысалы және 233 тексеру мысалы. Бұл сандар модель сапасын өлшемейді.

Оқыту деректерін жаңарту:

```sh
npm run training:dataset
```

Нәтиже `training/data/dosha-train.jsonl`, `dosha-validation.jsonl` және `manifest.json` файлдарына жазылады. Бұл файлдар Git-ке қосылмайды. Генераторды іске қосу модель салмақтарын өзгертпейді. Қазір білімді пайдалану іздеу арқылы іске асады; модельді бөлек оқыту үшін `training/train_dosha.py` мен оның GPU ортасы қажет.

Тексеру: `npm run typecheck` және `npm test`.
